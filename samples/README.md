# 内置词库（samples/）

本目录存放**随仓库提交的正式词库**与**导入模板**。仓库初始化、自动化测试（`tools/selftest.html`、
`tools/uismoke.html`）都直接读取这里的文件，替换文件时请同步更新这两处引用。

|---|---|---|---|---|---|

## 二、数据格式要求

必需字段：`word`（单词）、`meaning`（释义）——缺任一行被判为格式错误并跳过，不会静默进词库。
可选字段（自动识别，中英文表头均可映射）：`phonetic`、`phonetic_us`、`pos`、`collocation`、
`derivative`、`example`、`example_cn`、`level`、`stage`、`freq_rank`、`index`。

- 编码：UTF-8（带不带 BOM 均可），分隔符自动识别 `,` / `\t` / `;`
- `stage` / `level` 用于「按分类选题」「按使用频次选题」，缺失时导入页可选「统一填写」指定
- `freq_rank` 缺失时，`level` 也缺失的条目在频次维度会被归为「未标注」

## 三、导入模板（练手用）

`模板-标准字段.csv` / `.tsv` / `.json`、`模板-words外壳.json`（`{words:[...]}` 结构）、
`模板-Excel.xlsx`（含 sheet1 标准数据 + sheet2 一行无音标数据）。由 `python tools/make_samples.py`
重新生成（该脚本**不会**覆盖上表的正式词库）。
